# SafeDeal Frontend

중고거래 사기를 줄이는 **인증샷 검증 기반 중고거래 플랫폼 SafeDeal**의 프론트엔드입니다.
판매자가 챌린지 코드가 적힌 인증샷을 올리면, 서버가 위조 여부를 검증해 매물에 ✅ 인증됨 / ⚠️ 미인증 / 🚫 위조 의심 배지를 붙입니다.

- 백엔드: [safeDeal-platform/safeDeal-Backend](https://github.com/safeDeal-platform/safeDeal-Backend)
- 팀: Safe-Deal

## 🧱 기술 스택

| 구분 | 내용 |
|---|---|
| 프레임워크 | React (SPA) |
| 빌드 도구 · 언어 · 라이브러리 | _(스캐폴딩 시 확정 후 기재)_ |

## 🗺️ 주요 화면 (예정)

- 회원가입 · 로그인 · 소셜 로그인 · 이메일 인증 · 비밀번호 재설정
- 매물 목록(무한 스크롤) · 상세 · 등록
- 인증샷 검증 (챌린지 코드 발급 → 촬영 → 결과 조회)
- 채팅 (WebSocket)
- 결제 (PortOne)
- 신고 · 알림
- 관리자 검수

## 🚀 배포 구조

```
사용자 → CloudFront ─┬─ /*      → S3 (React 빌드 파일)
                     └─ /api/*  → ALB → 백엔드(ECS/Fargate)
```

- 프론트 배포: `빌드` → `S3 sync` → `CloudFront 캐시 무효화`
- 브라우저 입장에서 API는 같은 도메인의 `/api/*` 입니다.
